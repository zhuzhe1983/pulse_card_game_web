# 中英文界面

支持简体中文（`zh-CN`）与英语（`en`）。大厅、图鉴和费用曲线的页头提供语言按钮；对局中打开「菜单」切换，组牌页与卡牌详情也有入口。首次按浏览器语言选择，其他语言回退中文。

语言优先级：URL 的 `?lang=en` / `?lang=zh-CN` → 本机保存的选择 → 浏览器语言 → 中文。切换会更新当前 URL，并保存在 `localStorage` 的 `pulse.locale`。站内页面链接携带语言参数；浏览器禁止本地存储时，跳转和刷新仍能沿用语言。

切换不刷新页面、不重开对局，不改变选牌、资源、回合、随机种子或历史日志。图鉴保留搜索、筛选和当前卡牌；中文游戏名、英文游戏名及官方型号都可搜索。界面涵盖卡名、技能、出牌提示、错误、战斗记录、组牌、NFC 提示、图鉴详情与费用曲线。旧 v8 技能原文和技术路径保留原文，并标出来源；官方型号与素材里的产品文字不改写。

## 实现

- `shared/i18n.js`：语言选择、切换控件、文本格式化和 DOM 写入接口；无第三方运行依赖。
- `shared/locales/en.json`：英文词条源文件，中文原文作为键，动态值用 `{0}` 等占位。
- `shared/locales/en.js`：构建生成的浏览器词库，不手改。
- `src/clash/app.js`、`wiki/wiki.js`：在 `setHTML` / `setText` / `setAttr` 写入边界翻译。引擎、数值、标识符及日志数据继续使用原始内容；翻译只影响显示。
- `tools/build_clash.py`：生成词库和牌桌，并给共用脚本、样式与词库引用加内容版本，避免更新时混用旧缓存。

添加文案时同步补 `en.json`，再构建。未找到词条时显示中文，并记录到 `PULSEI18n.missing`，便于开发排查。对包含多个长句或来自数据的独立字段，用独立文本节点呈现，避免多个任意长度占位之间的分隔歧义。原文和变量都经过既有的 HTML 转义，译文只写入文本节点或属性。

图鉴的定费理由来自旧基线，已明确标为「基线定费说明」；当前攻耐与费用仍以战术覆盖后的数值栏为准。

## 验证

```bash
python3 tools/build_clash.py
node tools/check.cjs
PULSE_TEST_URL=http://127.0.0.1:8002 node tests/i18n.browser.cjs
PULSE_TEST_URL=http://127.0.0.1:8002 node tests/tactical.browser.cjs
```

本机未安装 Playwright 时用 `PLAYWRIGHT_MODULE_PATH` 指向可用模块。浏览器测试使用无头模式，并在 `finally` 关闭浏览器。

自动检查覆盖语言优先级、存储被禁用、切换前后对局状态一致、动态日志、双语搜索、详情和筛选保留、费用曲线，以及桌面、手机竖屏和横屏。翻译单测检查所有当前卡牌名称与技能、占位符和生成词库同步。截图位于 `output/playwright/`。
