# 电子工作台位图 UI

本游戏表现 ESP/M5 开发板和电子模块之间的对战。炉石是回合、费用与目标交互的玩法参考，不能据此使用原木酒馆、羊皮纸或中世纪装饰。早期原木概念已弃用，没有接入构建。

台面采用蓝灰防静电垫，边缘使用白色 ABS、拉丝铝、石墨密封条、深绿 PCB 与铜走线。少量青色和琥珀 LED 指示可操作状态、供电与攻耐。主体卡继续使用项目原有设备美术；技能卡使用独立电子动作插画，画面是游戏演绎，不作为设备功能的事实说明。

## 资源

内置 `image_gen` 生成，未使用 API CLI。全部原稿已复制到仓库，运行文件使用 WebP，保留透明通道。素材大小合计约 4.15 MB，按页面实际引用加载；PNG 原稿约 41 MB，不复制到 dist。

| 类别 | 文件 | 用途 |
| --- | --- | --- |
| 台面 | tabletop.webp | 完整电子工作台背景 |
| 卡框 | hand-frame.webp、unit-frame.webp | 手牌、战场模块的透明外壳 |
| 控件 | core-frame.webp、turn-button.webp | 生命核心、结束回合与打出按钮 |
| 卡背 | card-back.webp | 对手手牌、牌库与墓地标记 |
| 技能 | 以 template_id 命名的 12 个 WebP | 脉冲、电磁风暴、停机、重启、关机、修复、超频、编译及四个服务技能 |

完整生成提示词、生成来源和文件映射见 [manifest.json](../src/clash/scene/raster-v1/manifest.json)。原始 PNG 在同目录 `source/`。`content/clash/scene_assets.json` 是运行时资源映射；不要直接覆盖 dist 来修改素材。

## 接入与排版

`raster.css` 在 `tactical.css` 后加载，位图提供材质和外壳，文字、数值、选中光效和目标连线保留实时渲染。手牌插画和框架分层，费用与攻耐对齐生成图片的凹槽。手机手牌横滚；横屏低高度使用右侧双列滚动区。

生成式美术不能保证精确槽位，换卡框后必须对照实际 PNG 检查插画窗口、文字区和数字槽。用 `tools/build_clash.py` 重新构建，再运行规则及浏览器检查；截图应等待图片解码完成，不能以空插画帧作为验收结果。

本版检查了 1440×900、390×844、375×667、768×1024、844×390，包含满场、技能目标、拖拽、AI、本地交接、结算与重开。自动化检查不代替实体手机触摸和真人试玩。
