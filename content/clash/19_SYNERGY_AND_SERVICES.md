# 19 · 站位协同、上位连接、服务牌

规则集 `pcg.clash.v0`。数值是试玩草稿，**待试玩平衡**。费用曲线在 `docs/18_ROSTER_AND_GROWTH.md` 第 0 节。这一章的百分比、上位连接、三张服务牌和夺舍费用，在新曲线下核对后保持不变。

Grove 是现实里的接口，不进入规则。不写「每件产品都有 Grove」。配件怎么装到宿主上，仍用原来的配件规则。

## 1. 查过的事实

查阅日期 2026-11-11。下面是资料里写的用途。游戏效果在下一节，不把资料句子当成技能说明。

| 名字 | 资料里是什么 | 来源 |
|---|---|---|
| UIFlow / UiFlow | 图形化编程环境，用积木写程序，可以无线或有线（含 USB）下发到设备。桌面版是离线的 USB 编程。不是单纯的云存储。 | https://docs.m5stack.com/en/uiflow/uiflow_web 、 https://docs.m5stack.com/en/uiflow/uiflow_desktop |
| EzData 1.0 | 给 UiFlow 1.0 用的云端数据队列。用 token 调用 setData / getData。主题数量和条目数量有上限。 | https://docs.m5stack.com/en/arduino/ezdata/ezdata_arduino |
| EzData 2.0 | UiFlow2 账号下的物联网数据服务，用 MQTT 或 WebSocket，设备 token 来自注册。历史记录有上限，长时间空闲会清队列。和 UiFlow 的积木编程不是同一件事。 | https://docs.m5stack.com/en/guide/ezdata2/getting_started |
| AiFlow | 把自然语言写成 MicroPython，再下发、调试到 UiFlow2 能用的设备。网页有有限的试用额度；桌面版要用自己的模型接口。它不是 UIFlow 的积木。文档标题写作 AiFlow，产品地址里也出现 AIFlow。 | https://docs.m5stack.com/en/aiflow/usage 、 https://docs.m5stack.com/en/aiflow/web |
| M5Burner | 官方的本地固件烧录工具。可以烧 UiFlow 固件、写入 Wi-Fi，也可以导出和分享固件。资料没有说它能远程夺走别人的设备。 | 同上 UIFlow 文档对 M5Burner 的说明：烧录固件并配置 Wi-Fi |
| CardputerZero | 官方规格写明 CPU 为 RP3A0（BCM2837），四核 Cortex-A53，ARMv8-A。 | https://docs.m5stack.com/en/CardputerZero |
| CM4Stack | 本仓库研究目录记为树莓派 CM4、BCM2711，不是 ESP32。目录里的 SKU 是未知。它不在 96 张图里。 | `research/hardware_catalog.md` 的 H019 |
| CoreMP135 | 目录记为 STM32MP135、Cortex-A7。它是 Linux 宿主，但这次的上位机名单不收它。 | 同目录 H018 |

游戏不登录这些网站，也不调用它们的接口。

## 2. 事实到创作

| 事实 | 游戏里怎么用 | 明确不做 |
|---|---|---|
| UIFlow 是把积木程序做出来并下发 | 服务牌「积木开工」，3 费，抽 1 张 | 不加攻击，不模拟 USB |
| EzData 是把数据存进云端再取回 | 服务牌「记一笔」，2 费，取回自己墓地最上面一张 | 不要求账号，不堆一个没用掉的取回次数 |
| AiFlow 是用自然语言生成一段程序 | 服务牌「说人话」，4 费，本回合下一次打击在百分比前攻击 +2 | 不调用模型，不给每台单位永久加攻 |
| M5Burner 是把程序写进本地硬件 | 服务牌「夺舍」，7 费，选中的敌方主控改由我方控制 | 不声称现实里可以远程夺设备，不造成伤害，不复制一张新牌 |
| CardputerZero 的官方 CPU 是 Cortex-A53 | 96 张里的零键获得上位机资格。它是上位 ARM 整机，费用 10，攻击 4，耐久 7 | 不因为它是 ARM 就把所有 ARM 都标成上位机 |
| CM4Stack 在目录里是 BCM2711 | 单独的设计牌「树莓台」，可以发动上位连接。无 SKU，无图 | 不把它算进 96，不编造 SKU |
| CoreMP135 也是 ARM Linux | 只留在目录说明里 | 不能发动来自上位的爱，也不能被当成 ESP32 目标 |

服务牌和树莓台放在 `content/clash_services.json`。96 张硬件图册仍是 `content/clash_roster_96.json`。

## 3. Chain 站位

带 `chain_piece` 的配件装上宿主之后，还在该方队伍里放一个链节标记。基线的链节，以及 96 张里 `chain_nodes`、`chain_parts` 两族，都有这个标记。标记不是第二台攻击者，不能被选为攻击目标，耐久归零的检查会跳过它。

默认把标记追加到最右。要让它紧挨领队，出牌时写插入位置。位置 0 是最左。越界整步取消。

阵型百分比，每次攻击和反击前重算：

- 队伍最左是一台主控：10%。
- 从它右边第一格开始，连续的链节标记每个再 +5%。第一段就算。中间插进别的单位或非链节，连续就断，断点后面的链节不加。
- 最左不是主控，包括最左是链节标记：0%。空队伍也是 0%。
- 这是全队的打击和反击，不是只加给某一段。领队自己的攻击也吃到。
- 干扰、入场伤害这类固定数字不加百分比。

试玩比例是领队 10%，每一段连续 Chain 5%。没有把 5% 留空。

宿主死亡、升星丢掉配件、或者配件离开时，标记拿走。配件牌只进墓地一次，不因为标记再进一次。

## 4. 打击怎么算

先看攻击栏：卡面攻击 + 配件加成 + 本回合临时加成。

攻击栏小于等于 0 时，这次打击伤害是 0。百分比和加成都不把 0 变成伤害。

否则按这个顺序，只用于这一次伤害，不改写卡面上的攻击数字：

1. 该方至少有一条「来自上位的爱」：+1。两条也不再加。
2. 该方「说人话」还没被用掉：再 +2，然后这次加成消失。
3. 乘上阵型百分比，向上取整。整数式是 `(打击攻击 × (100 + 百分比) + 99) // 100`。

所以攻击栏 1、只有领队 10% 时，伤害是 2。攻击栏 1、再接一段 Chain（15%）时，伤害仍是 2。攻击栏 2、10% 时，伤害是 3。

## 5. 来自上位的爱

这是一场行动，不是一张服务牌。费用 1。

来源必须是己方场上的上位机主控。现在只有两台：零键，以及设计牌树莓台。零键的资格来自官方 Cortex-A53 规格。树莓台的资格来自目录里的 BCM2711 记录。

目标必须是己方场上的 ESP32 独立主控。基线六台主控标了这个资格。96 张里，硬件结论是独立宿主、芯片栏写有 ESP32 的主控也是目标。上位机自己、对方单位、基地、链节标记、配件、辅助单片机，都不是目标。CoreMP135 两边都不是。

一台来源同时只连一台，一台目标同时只被连一次。光环不按条数叠加。只要还留着至少一条：

- 该方每次打击在第 4 节的第 1 步 +1。
- 有效供电上限比成长上限再高 1，最高仍是 10。回合开始的回满用这个有效上限。

本回合第一次从 0 条变成 1 条时，当前供电再 +1，然后不超过有效上限，也不超过 10。同一回合把线拆掉再接上，不再给这 1 点。来源或目标因死亡、升星、被夺舍而离场，这条线断掉。最后一条断掉时，当前供电压回成长上限。

连接不触发出场，不刷新攻击次数和技能次数。非法目标不扣电。

## 6. 夺舍

费用 7。打出成功后这张牌进入自己墓地。

目标是敌方场上的一台主控。基地不能选。链节标记不能选。配件不能单独选，它留在宿主身上一起走。上位机和当前最左的领队都可以被选，没有额外免疫。

成功时：

- 控制权改到我方。默认排到我方队伍最右。它身上的链节标记跟到它右边。
- 当前耐久、伤害、护卫、配件都保留。不回满耐久，不变成白卡。
- 本回合不能攻击，也不能发动支援、旋钮或来自上位的爱。到我方下个回合开始才解除。
- 不触发出场、复活或刷电。不刷新本回合已经用过的支援、旋钮、升星退役标记。
- 涉及它的上位连接断掉。双方阵型按新队伍重算。
- 之后它死亡，进当前控制者的墓地。原来的主人不能用自己的小印支援这台厚壳。当前控制者可以，规则仍是小印支援自己墓地里的厚壳。
- 没有「死亡后自动还给原主人」。要再变更控制权，就再夺舍一次。

目标不存在、是基地、是链节、是己方单位时，整步取消，不扣 7 点电，牌还在手里。

## 7. 和升星、复活的关系

升星仍是原位置换成下一星，不是新的一次入场。不因为升星获得上位连接的那 1 点电，也不重复打出「说人话」。旧的上位连接随旧单位断掉。链节标记随旧配件离开。

支援复活的厚壳仍然插到最左，满耐久 7，本回合不能攻击。它若插到领队左边，阵型按新的最左重算。复活不自动接上上位连接。

1 费邮票的攻击是 1。领队 10% 把它打成 2，链节的平坦 +1 才会再往上走。铺一张 1 费邮票不会让全队都打出 3 点。夺舍仍是 7 费：拿走 1 费邮票不划算，拿走 6 费厚壳或 9 到 10 费的整机才是这张牌要做的事。服务牌费用不动。
