## 最小可玩路线

先做本地热座，双方共用一块屏幕，轮流操作。不要接旧裁判，不要洗牌，不要 NFC。

1. 读卡表。牌库用 JSON 里的 `decks.first` 和 `decks.second`，列表第 0 张在顶。
2. 起手：先手 3 张，后手 4 张，后手手牌再加 `jie_yi_ge_dian`。
3. 座位 0 先手。按钮「结束回合」先做回合结束，再立刻做对方的回合开始。
4. 打到教学局第 3 回合结束，局面必须和 fixture 最后一个 `t3_end` 一致：基地 20 对 19，先手场上只有点阵哨，后手场上只有细条。
5. 再做第 01 章第 8 节的两条支援。小印留在场上，复活的是厚壳。

## 局面

两边各有：基地、当前供电、供电上限、手牌、牌库张数、疲劳次数、5 个位置、墓地。

每个位置空着，或有一台主控：卡牌 id、当前攻击、耐久、是否新入场、是否已攻击、是否护卫、配件 id 列表。攻击 = 卡面攻击 + 配件加成 + 本回合临时加成。

自己看见自己的手牌。对方只看见张数。墓地双方都看见，按进入顺序，不能重排。

## 回合顺序

1. 先手第 1 回合不抽牌。其余回合抽 1 张。
2. 抽牌时手牌已有 8 张：亮牌，进入自己墓地，不触发出场。
3. 牌库空：疲劳次数 +1，只扣正在抽牌的一方基地，点数等于这次疲劳次数。基地到 0 就终局，不加供电，也不解除新入场。
4. 没终局：该方场上原来的单位解除新入场和已攻击。供电上限 +1，最高 10。当前供电设成上限。
5. 主阶段可以出牌、支援、旋钮、攻击，顺序自定。
6. 结束：清掉该方临时攻击和已攻击，供电清零，轮到对方，马上回到第 1 步。

位置 0 到 4 从左到右。出牌和支援都进最左边的空位。

## 行动

非法行动整步取消，供电、手牌、标记都不变。终局后一律拒绝。

| 行动 | 合法时发生什么 |
|---|---|
| `play` 主控 | 扣费，进最左空位，新入场不能攻击 |
| `play` 配件 | 扣费，挂到指定的己方主控。一台只能挂一个。护罩不能装到已有护卫的单位 |
| `play` 战术 | 扣费，立刻结算，然后进自己墓地 |
| `support` | 场上的小印花 2 点电。自己墓地里的厚壳进最左空位，耐久 6，有护卫，无配件，本回合不能攻击。小印留在场上。每玩家每回合 1 次 |
| `knob` | 场上的旋钮台花 1 点电，一个己方单位（可以是自己）本回合攻击 +1。每回合 1 次。新入场也能用 |
| `attack` | 新入场不能打，一台一回合一次。打单位时先抄下双方攻击，再同时扣耐久，再一次性死亡。打基地不反击 |
| `end_turn` | 见上面第 6 步 |
| `promote` | 场上这一星换成手牌里的下一星。费用是差价，最少 1。没有降星。新主控进原位置，满耐久，本回合不能攻击，不带配件。旧配件先入墓地。升星不刷新本回合已经用过的支援或旋钮。本回合因此退役的厚壳不能马上被支援召回 |

借一格电是 0 费，当前供电 +1，可以暂时高于上限。回合结束清零。

干扰只打敌方单位，护卫拦不住，没有反击。补给只能选己方单位：恢复 2 点耐久且不超过卡面，或本回合攻击 +1。回充给自己基地加 4，不超过 20。

同时死亡：先座位 0，再座位 1；同一边按位置从小到大。每台先把配件送进墓地，再送自己。这个窗口里不能插支援。

对方有护卫时，没有千里眼的攻击只能打护卫中的一台。千里眼只忽略护卫，不额外加攻击。

## 错误码

网页可以按码提示，不必解析中文句子。拒绝时局面与行动前相同。

`game_over` `not_your_turn` `bad_phase` `not_enough_supply` `not_in_hand` `board_full` `bad_target` `already_has_attachment` `already_has_guard` `no_stamp_on_board` `no_shell_in_grave` `already_used_ability` `summoning_sickness` `already_attacked` `guard_blocks` `no_growth`

同一回合里支援或旋钮已经用过，再试一次报 `already_used_ability`，即使当时也没电。第一次用、但是电不够，才报 `not_enough_supply`。

## 验收清单

- 教学局走到 `t3_end`，基地、手牌、墓地、场上和 fixture 一致。
- 借一格电打出后当前电是 2，上限仍是 1；回合结束变 0。
- 先手第 1 回合不抽牌。后手第 1 回合抽到点阵哨。
- 新入场单位攻击被拒绝，局面不变。
- 两台小印对砍后同时进墓地，先手先，后手后。
- 小印已在场：花 2 电复活厚壳，小印还在，再支援一次不扣电。
- 小印在手牌：先支援被拒绝且不扣电；打出后再花 2 电才能复活。
- 满 5 个位置时支援不扣电。
- 配件装到对方、第二件配件、给已有护卫装护罩，都不扣电。
- 宿主死亡时墓地顺序是配件、宿主。
- 手牌 8 张再抽，那张牌进墓地，手牌仍是 8。
- 疲劳把基地打到 0 时，供电上限不加，之后不能出牌。
- 疲劳没打死时，先扣血，再把供电上限加 1 并回满。
- 终局后出牌、攻击、支援、结束回合都失败。
- 画面不使用 `pcg.core.v1` 的小局、战力和停手。

## 游戏角色和硬件

`game_role` 是回合里的身份。`hardware_controller` 是目录里的硬件结论。`art_type` 是卡面 type A / B，按硬件自己的卡面家族，这张表里是空的。链节的角色是配件，硬件是辅助可编程单片机，不是无主控，也不是 Chain DualKey。
