## 最小可玩路线

先做本地热座，双方共用一块屏幕，轮流操作。不要接旧裁判，不要洗牌，不要 NFC。

1. 读卡表。牌库用 JSON 里的 `decks.first` 和 `decks.second`，列表第 0 张在顶。
2. 起手：先手 3 张，后手 4 张，后手手牌再加 `jie_yi_ge_dian`。
3. 座位 0 先手。按钮「结束回合」先做回合结束，再立刻做对方的回合开始。
4. 打到教学局第 3 回合结束，局面必须和 fixture 最后一个 `t3_end` 一致：基地 20 对 18，先手场上只有点阵哨，后手场上没有单位。领队 10% 已经算进这些伤害。
5. 再做第 01 章第 8 节的两条支援。小印留在场上，复活的是厚壳。

## 局面

两边各有：基地、当前供电、供电上限、手牌、牌库张数、疲劳次数、从左到右的单位队列、墓地。队列没有固定长度，也不设 5、7、10 这类上限。

队列里每一台主控：卡牌 id、当前攻击栏、耐久、是否新入场、是否已攻击、是否护卫、配件 id 列表。攻击栏 = 卡面攻击 + 配件加成 + 本回合临时加成。链节标记跟在队列里，标成 link，不能攻击，也不能被选为目标。没有空位占位符。

伤害另算，不改攻击栏。攻击栏小于等于 0 时伤害是 0。否则加上位连接的 1（有连接才加，多条不叠加），再加上说人话剩下的 2（打出这一下就用掉），再乘阵型百分比并向上取整：`(打击攻击 * (100 + 百分比) + 99) // 100`。干扰和入场伤害不加这些。

自己看见自己的手牌。对方只看见张数。墓地双方都看见，按进入顺序，不能重排。

## 回合顺序

1. 先手第 1 回合不抽牌。其余回合抽 1 张。
2. 抽牌时手牌已有 8 张：亮牌，进入自己墓地，不触发出场。
3. 牌库空：疲劳次数 +1，只扣正在抽牌的一方基地，点数等于这次疲劳次数。基地到 0 就终局，不加供电，也不解除新入场。
4. 没终局：该方场上原来的单位解除新入场和已攻击。供电上限 +1，最高 10。当前供电设成上限。
5. 主阶段可以出牌、支援、旋钮、攻击，顺序自定。
6. 结束：清掉该方临时攻击和已攻击，供电清零，轮到对方，马上回到第 1 步。

下标 0 是最左。出牌不写 `index` 就追加到最右。写了 `index` 就插入该处，范围是 0 到当前张数，含“排到最后”。越界整步取消，错误码 `bad_index`。支援不看 `index`，厚壳永远插到最左，其余右移。升星替换原下标，左右邻居不动。

## 行动

非法行动整步取消，供电、手牌、标记都不变。终局后一律拒绝。

| 行动 | 合法时发生什么 |
|---|---|
| `play` 主控 | 扣费。不写 `index` 就排到最右；写了就插入。新入场不能攻击 |
| `play` 配件 | 扣费，挂到指定的己方主控。一台只能挂一个。护罩不能装到已有护卫的单位 |
| `play` 战术 | 扣费，立刻结算，然后进自己墓地 |
| `support` | 场上的小印花 2 点电。自己墓地里的厚壳插到最左，耐久 6，有护卫，无配件，本回合不能攻击。小印留在场上。每玩家每回合 1 次。不受张数限制 |
| `knob` | 场上的旋钮台花 1 点电，一个己方单位（可以是自己）本回合攻击 +1。每回合 1 次。新入场也能用 |
| `attack` | 新入场不能打，一台一回合一次。打单位时先按上面的公式抄下双方伤害，再同时扣耐久，再一次性死亡。打基地不反击。反击方的阵型用反击方自己的队伍 |
| `upper_link` | 来自上位的爱。己方上位机花 1 点电，连到己方一台 ESP32 主控。零键和树莓台是上位机。CoreMP135 不是。每台来源一条，每台目标一条。本回合第一次接上时当前供电 +1，同一回合重连不再给 |
| `play` 服务牌 | 积木开工 3 费抽 1。记一笔 2 费取回自己墓地顶；空墓地也消耗。说人话 4 费，本回合下一次打击在百分比前 +2。夺舍 7 费，见下 |
| `end_turn` | 见上面第 6 步。说人话没用掉也清掉 |
| `promote` | 场上这一星换成手牌里的下一星。费用是差价，最少 1。没有降星。新主控进原位置，满耐久，本回合不能攻击，不带配件。旧配件先入墓地。升星不刷新本回合已经用过的支援或旋钮，也不当成新入场去刷电。本回合因此退役的厚壳不能马上被支援召回 |

夺舍的目标是敌方场上主控。基地、链节标记、己方单位非法。上位机和最左领队可以夺。成功后排到我方最右，链节标记跟过去，耐久和配件保留，本回合不能攻击也不能发动技能，不回血，不触发出场。死亡进当前控制者墓地。原来的主人不能支援这台厚壳。涉及它的上位连接断开。

阵型：最左是主控则 10%，右边连续链节标记每个 +5%。最左不是主控则 0%。部署、死亡、支援、升星、夺舍之后都按当时队伍重算。

借一格电是 0 费，当前供电 +1，可以暂时高于上限。回合结束清零。

干扰只打敌方单位，护卫拦不住，没有反击。补给只能选己方单位：恢复 2 点耐久且不超过卡面，或本回合攻击 +1。回充给自己基地加 4，不超过 20。

同时死亡：先座位 0，再座位 1；同一边按位置从小到大。每台先把配件送进墓地，再送自己。这个窗口里不能插支援。

对方有护卫时，没有千里眼的攻击只能打护卫中的一台。千里眼只忽略护卫，不额外加攻击。

## 错误码

网页可以按码提示，不必解析中文句子。拒绝时局面与行动前相同。

`game_over` `not_your_turn` `bad_phase` `not_enough_supply` `not_in_hand` `bad_index` `bad_target` `already_has_attachment` `already_has_guard` `no_stamp_on_board` `no_shell_in_grave` `already_used_ability` `summoning_sickness` `already_attacked` `guard_blocks` `no_growth` `seized_this_turn`

同一回合里支援或旋钮已经用过，再试一次报 `already_used_ability`，即使当时也没电。第一次用、但是电不够，才报 `not_enough_supply`。

## 验收清单

- 教学局走到 `t3_end`，基地、手牌、墓地、场上和 fixture 一致。
- 借一格电打出后当前电是 2，上限仍是 1；回合结束变 0。
- 先手第 1 回合不抽牌。后手第 1 回合抽到点阵哨。
- 新入场单位攻击被拒绝，局面不变。
- 教学局里，领队 10% 使细条打基地造成 2 点，后手基地是 18。第 2 回合后手小印和先手细条同时死亡。第 3 回合先手小印和后手细条同时死亡。
- 链节标记接在领队右边时百分比变成 15。标记放到最左时百分比是 0。宿主死亡后标记消失，配件只进墓地一次。
- 来自上位的爱拒绝 CoreMP135、对方单位和链节标记，并且不扣电。两条连接不把攻击加成变成 +2。同一回合重连不再给当前供电。
- 积木开工抽一张。记一笔在墓地为空时仍然消耗。说人话武装时再打一张不扣电。干扰不吃说人话的 +2。
- 夺舍保留受伤和配件，当回合不能攻击。被夺的厚壳死后进新控制者墓地，原主人支援失败。
- 小印已在场：花 2 电复活厚壳，小印还在，再支援一次不扣电。
- 小印在手牌：先支援被拒绝且不扣电；打出后再花 2 电才能复活。
- 场上已有 5 台时，支援和部署仍然成功，可以变成 6 台、7 台。没有另设上限。
- 插入位置越界时不扣电，队伍不变。
- 配件装到对方、第二件配件、给已有护卫装护罩，都不扣电。
- 宿主死亡时墓地顺序是配件、宿主。
- 手牌 8 张再抽，那张牌进墓地，手牌仍是 8。
- 疲劳把基地打到 0 时，供电上限不加，之后不能出牌。
- 疲劳没打死时，先扣血，再把供电上限加 1 并回满。
- 终局后出牌、攻击、支援、结束回合都失败。
- 画面不使用 `pcg.core.v1` 的小局、战力和停手。

## 游戏角色和硬件

`game_role` 是回合里的身份。`hardware_controller` 是目录里的硬件结论。`art_type` 是卡面 type A / B，按硬件自己的卡面家族，这张表里是空的。链节的角色是配件，硬件是辅助可编程单片机，不是无主控，也不是 Chain DualKey。
